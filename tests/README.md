# Ваши тесты

- `tests/unit/` — юнит-тесты бизнес-логики (сервисный слой, хеширование,
  генерация/валидация JWT) без поднятого сервиса. Минимум 5.
- `tests/integration/` — интеграционные тесты по HTTP для эндпоинтов,
  которые НЕ покрыты обязательными `contract_tests/` (`/register` и
  `/login` уже проверены преподавателем): `/refresh`, `/user/update`,
  `/user/history`, `/logout`, `/user/me`. Требуют поднятого сервиса
  (`make up`), читают адрес из `AUTH_SERVICE_URL`
  (по умолчанию `http://localhost:8002`), как и `contract_tests/`.

Обязательно проверить в своих интеграционных тестах:

- ротацию refresh-токена: повторное использование уже использованного
  refresh должно вернуть 401;
- что после `/logout` и access, и refresh перестают работать (401);
- что `/user/history` растёт после повторного логина.

Для проверки истечения access-токена без ожидания реального TTL —
задайте в своём окружении `ACCESS_TOKEN_TTL_SECONDS=2` и подождите
2+ секунды перед запросом.
