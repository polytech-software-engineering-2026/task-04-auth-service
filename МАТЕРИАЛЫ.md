# Материалы к заданию

## JWT

- [jwt.io — Introduction](https://jwt.io/introduction) — структура токена, claims, подпись
- [PyJWT — документация](https://pyjwt.readthedocs.io/en/stable/) — если выбираете эту библиотеку
- [FastAPI — OAuth2 with Password (and hashing), Bearer with JWT tokens](https://fastapi.tiangolo.com/tutorial/security/oauth2-jwt/) — официальный туториал именно на эту задачу

## Хеширование паролей

- [passlib — документация](https://passlib.readthedocs.io/en/stable/) — bcrypt через единый интерфейс
- [argon2-cffi — документация](https://argon2-cffi.readthedocs.io/en/stable/) — если выбираете argon2

## Redis

- [redis-py — документация](https://redis.readthedocs.io/en/stable/) — официальный клиент
- [Redis — EXPIRE](https://redis.io/docs/latest/commands/expire/) — TTL для отозванных токенов: не нужно чистить их вручную, если TTL совпадает с временем жизни токена

## FastAPI: зависимости и авторизация

- [FastAPI — Security](https://fastapi.tiangolo.com/tutorial/security/)
- [FastAPI — Dependencies with yield](https://fastapi.tiangolo.com/tutorial/dependencies/dependencies-with-yield/) — для сессии БД и получения текущего пользователя из Bearer-токена

## SQLAlchemy 2.x и Alembic

- [SQLAlchemy 2.0 — ORM Quick Start](https://docs.sqlalchemy.org/en/20/orm/quickstart.html)
- [Alembic — Tutorial](https://alembic.sqlalchemy.org/en/latest/tutorial.html)

## OWASP

- [OWASP API Security Top 10](https://owasp.org/API-Security/editions/2023/en/0x00-header/) — особенно Broken Authentication и Broken Object Level Authorization — прямо про то, что делает этот сервис
