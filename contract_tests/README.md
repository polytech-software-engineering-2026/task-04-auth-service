# Контрактные тесты (заглушка)

Появятся к неделе 13 вместе с docker-compose джобой в CI. Будут читать
базовый URL из `AUTH_SERVICE_URL` (по умолчанию `http://localhost:8002`)
и проверять полный жизненный цикл токенов: истёкший access
(`ACCESS_TOKEN_TTL_SECONDS=2` в CI), повторное использование refresh
после ротации → 401, доступ после logout → 401, рост истории входов
после второго логина.
